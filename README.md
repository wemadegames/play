# Class Arcade

Four browser games designed by middle-school students and built with AI, then combined into one arcade menu. Pure HTML, CSS, and vanilla JavaScript. No build step, no backend.

## Games

| Group | Game | Folder |
|-------|------|--------|
| 1 | Escape the Police | `group1/` |
| 2 | Leave the Maze | `group2/` |
| 3 | Spellbound Academy | `group3/` |
| 4 | Football Fusion | `group4/` |

## Play locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8123
```

Then visit `http://localhost:8123/`.

## How it was made

Students acted as game designers. They described what they wanted in plain language, the AI turned each idea into code, and the class played the result. Idea, prompt, build, play, review.
